# b_mstruct (BL641 Meta Structures)

**b_mstruct** — это библиотека динамических структур данных для языка C. В основе лежит подход type erasure (`void*`), а типобезопасные обертки генерируются с помощью препроцессора.

Проект пишется для практики системного программирования. Идея в том, чтобы не тащить C++ ради базовых контейнеров, а реализовать их вручную на чистом C с полным контролем над памятью.

## Возможности

*   **Type Erasure и макросы:** Логика работы написана один раз на `void*`. Типизированные обертки генерируются на этапе компиляции, чтобы не раздувать бинарник.
*   **Итераторы:** Поддержка `begin` и `end` для классических циклов.
*   **Защита от ошибок:** Проверки на `NULL`, выход за границы и обработка нехватки памяти (OOM).

## Что реализовано

*   `bvector` — динамический массив. Поддерживает `push`, `pop`, `at`, итераторы, `insert`, `erase`, `clear` и `reserve`.
*   `barray` — массив фиксированной ёмкости. Поддерживает добавление в конец, доступ по индексу, удаление, заполнение, зануление элемента и итераторы. При полной ёмкости не растёт, а возвращает ошибку.
*   `bpair` — пара значений (в процессе).

## Как использовать (на примере bvector)

Сначала генерируем обертки под нужный тип:

```c
#include <stdio.h>
#include "bvector.h"

// Генерируем функции с префиксом int_vec для типа int
bvector(int_vec, int)

int main() {
    // Создаем вектор с начальной емкостью 10
    vector* v = int_vec_init(10);
    
    // Добавляем элементы
    for (int i = 0; i < 5; i++) {
        int_vec_push(v, i * 10);
    }

    // Читаем элементы через итераторы
    for (int* it = int_vec_beg(v); it != int_vec_end(v); it++) {
        printf("%d ", *it);
    }
    printf("\n");

    // Читаем через безопасный at (при ошибке вернет 0)
    printf("Element at 2: %d\n", int_vec_at(v, 2));

    // Вставляем 777 на позицию 1
    int_vec_ins(v, 1, 777);

    // Удаляем элемент с позиции 2
    int_vec_ers(v, 2);

    // Освобождаем память
    vec_free(v);
    return 0;
}
