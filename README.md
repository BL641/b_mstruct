# b_mstruct (BL641 Meta Structures)
**b_mstruct** — это легковесная библиотека структур данных для языка C, использующая возможности препроцессора для создания типобезопасных контейнеров. (аналог STL из C++);

Данный проект создан для того, чтобы в первую очередь, развить мои навыки Си, а также и потому, что основное влияние на разработку данного кода лично для меня является любовь к языку Си и
нежелание прибегать к С++, тогда когда есть вариант от него отказаться.

## Возможности 
*   **Типобезопасность:** Компилятор не позволит положить `double` в вектор, созданный для `int`.
*   **Генерация кода на этапе компиляции:** Благодаря макросам, код работает так же быстро, как если бы вы написали его вручную.
*   **Управление памятью:** Автоматическое расширение (capacity) при добавлении элементов.
*   **Нулевые зависимости:** Только стандартная библиотека C (`stdlib.h`, `string.h`).


##  Что уже реализовано
*   `bvector` — динамический массив (вектор) для любого типа данных.

##  Как использовать
Библиотека работает в два этапа: генерация типа и использование.

### 1. Подключение и генерация
Подключите заголовочный файл и вызовите макрос для нужного типа:
```c
#include "bvector.h"

// Генерируем вектор для int и double
bvector(int)
bvector(double)

int main() {
    // Создаем вектор на 10 элементов
    vector_int* v = vector_int_init(10);
    
    // Добавляем элементы
    v_int_pback(v, 42);
    v_int_pback(v, 100);
    
    // Читаем элементы
    for (size_t i = 0; i < vector_int_size(v); i++) {
        printf("%d ", v->data[i]);
    }
    
    // Освобождаем память
    v_int_free(v);
    return 0;
}
